# AI Producer Animated Prototype

Standalone web prototype for the `AI PRODUCER` Figma flow.

## What is included

- Figma flow implementation for `AGNETICS.AI-PRODUCER` node `4009:4704`.
- Start screen, segmented prompt modes, option picking, selected style strip, and result/video editor screen.
- Local Figma assets for genre cards, atmosphere options, video frame, timeline, and style orb.
- UI kit icon assets pulled from `AI_PRODUCER_UIKIT` node `271:1030`.
- Typography tokens based on `AI_PRODUCER_UIKIT` typography page `271:733`.

## Files

- `ai-producer-prototype.html` - main standalone prototype.
- `assets/figma/hero-ice-sphere.png` - exported hero image from Figma.
- `assets/figma-flow/final/*` - exported Figma flow assets.
- `assets/uikit-icons/*.svg` - local UI kit icon assets.

## Run

Open `ai-producer-prototype.html` in a browser.

No build step is required.
