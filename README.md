# danyatroyanov.com

Сайт-портфолио Даниила Троянова, продуктового AI-дизайнера. Дизайн — в Figma, код собран вместе с AI-агентами: Claude Code и Codex.

**→ [danyatroyanov.com](https://danyatroyanov.com)**

## Кейсы

| Страница | Проект |
|---|---|
| [`artifact.html`](https://danyatroyanov.com/artifact.html) | ARTIFACT — мобильное приложение для создания AI-картинок и видео |
| [`ai-producer.html`](https://danyatroyanov.com/ai-producer.html) | AI Producer — веб-платформа для сборки AI-сцен с режиссёрским контролем |
| [`taya.html`](https://danyatroyanov.com/taya.html) | TAYA — AI-компаньон для независимых художников |

## Стек

- **React 19 + Vite 7.** Сборка мультистраничная: главная написана на React, кейсы — статические страницы. Входы перечислены в `vite.config.js`.
- **three.js и @react-three/fiber** — WebGL-аватар на главной. На телефонах и при `prefers-reduced-motion` WebGL не загружается, остаётся обычное видео.
- **Lenis** — плавная прокрутка.

## Структура

```
index.html, src/        главная (React)
*.html, *.css           кейсы: artifact, ai-producer, taya
bottom-nav.css          нижняя навигация, общая для всех страниц
media-playback.js       видео играет, только пока оно на экране и вкладка открыта
smooth-scroll.js        плавная прокрутка
assets/                 медиа, появление блоков при прокрутке (reveal.js)
prototype/              интерактивные прототипы продукта для кейса AI Producer, в сборку сайта не входят
scripts/                деплой на Beget, обработка видео аватара
tests/                  проверки сборки
```

## Запуск

```bash
npm install
npm run dev     # 127.0.0.1:4174
npm test        # собирает сайт и проверяет, что в сборку попали все страницы и медиа
npm run build   # сборка в dist/
```

Проверять стоит собранный `dist/`, а не дев-сервер: между ними есть разница, и она уже ломала прод. Подробности — в `AGENTS.md`.

## На что посмотреть

- **Клик не превращается в перетаскивание.** Лента шотов на главной тянется мышью, но дрогнувшая рука при клике её не сдвинет: захват начинается только после 6 px. Смотри `DragScroll` в `src/App.jsx`.
- **Звук у видео.** Включается с плавным нарастанием громкости, глушит остальные ролики и выключается сам, когда видео уходит с экрана. Смотри `SoundButton` в `src/App.jsx`.
- **Прогрессивный блюр** нижней кромки экрана собран из четырёх слоёв с полосовыми масками. Один слой с градиентной маской даёт видимые ступени, полосы — нет. Смотри `ProgressiveBlur` в `src/App.jsx`.
- **Навигация на токенах.** Нижняя панель одна на все страницы и живёт на наборе CSS-переменных `--nav-*`, а каждая страница маппит на них свои токены. Смотри `bottom-nav.css`.
